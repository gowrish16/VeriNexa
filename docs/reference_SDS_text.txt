1. System Design 
The proposed system is a web-based machine learning application that classifies news headlines into 
four categories: POLITICS, SPORTS, BUSINESS and ENTERTAINMENT. It uses Natural Language 
Processing (NLP), TF-IDF feature extraction and the LinearSVC classification algorithm. 
1.1 Architectural Design 
The application has three main parts: the React frontend, the Python Flask backend and the machine 
learning model. SQLite is used for application data storage. The frontend accepts a headline and 
displays the prediction. The backend processes the request and communicates with the trained model. 
1.1.1 System Context Diagram 
Figure 1 shows the main external user, dataset and application components and how they exchange 
information. 
 
Figure 1: System Context Diagram 
 
The user enters a headline through the frontend. The frontend sends it to Flask. The backend applies the 
same text preparation and TF-IDF transformation used during training. LinearSVC predicts a category

2.2 Preprocessing and Feature Engineering 
Preprocessing prepares headline text before it is passed to the classification model. It helps make the 
text consistent and removes content that is not useful for classification. 
2.2.1 Validation and Cleaning 
• Data validation checks that the required headline and category fields are present. 
• Missing-value handling identifies and treats records with missing values. 
• Duplicate checking identifies repeated records. 
• Text cleaning removes unnecessary characters and symbols. 
• Text normalization makes the text consistent. 
• Tokenization divides a headline into individual words. 
• Stop-word removal may remove common words when appropriate. 
Example: “The Team Wins The Final Match!” becomes “team wins final match” after a simple cleaning 
process. The exact cleaning operations should match the implementation. 
2.2.2 Feature Selection / Extraction 
The project uses TF-IDF (Term Frequency–Inverse Document Frequency). It converts cleaned headline 
text into numerical values so the machine learning algorithm can process it. The interface shows a 
maximum of 12,000 features.

2.3 Model Design 
The machine learning model learns patterns between headline text and category labels. TF-IDF is used 
to extract features, and LinearSVC is the primary classification algorithm shown in the project interface.
